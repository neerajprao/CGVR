Two-Dimensional Transformations

Translation • Rotation • Scaling • Reflection • Shearing • Homogeneous Coordinates

Start here What you are about to learn

A transformation is a rule that takes every point of an object and moves it to a new place.

The object itself never "knows" it moved. All that changes are its coordinates. Every effect you have seen in a game, a photo editor or a CAD tool — sliding, spinning, zooming, mirroring, slanting — is one of these five rules applied to a list of points.

The formal version: a 2D geometric transformation maps each point P(x, y) to a new point P'(x', y') using a fixed set of equations. The five transformations below are affine: straight lines stay straight and parallel lines stay parallel.

01 What is it

Before you can move a shape, you need an address system for every point on the screen.

That address system is the Cartesian plane. Two number lines cross at right angles. The horizontal line is the x-axis, the vertical line is the y-axis, and the crossing point is the origin, written O(0, 0).

A point is written P = (x, y)  — x first (how far right), y second (how far up).

Every transformation in this lesson does exactly one thing: it takes the numbers x and y and produces new numbers x' and y'. Nothing else changes.

01 What is it

Translation moves an object from one position to another without changing its size, shape or orientation.

Think of sliding a book across a table. Every corner of the book travels the same distance in the same direction. In graphics that distance is stored as two numbers: Tx (how far along x) and Ty (how far along y).

Deeper: translation is a rigid body transformation — distances between points and angles inside the object are both preserved.

01 What is it

Rotation turns an object around a fixed point, called the pivot or rotation centre.

Every point of the object travels along a circle centred on the pivot. The default pivot is the origin O(0, 0). A positive angle turns counter-clockwise; a negative angle turns clockwise.

Deeper: like translation, rotation preserves distances and angles — only the orientation changes. The distance of each point from the pivot stays exactly the same.

x' = x·cos θ − y·sin θ
y' = x·sin θ + y·cos θ

Watch the minus sign: it sits in the top-right position for counter-clockwise rotation. Flip the sign of θ and the two sine terms swap signs, giving clockwise rotation.

In homogeneous 3×3 form the rotation block sits in the top-left corner and the third column stays empty because rotation about the origin involves no shifting:

Rotating about any other pointMove the pivot to the origin, rotate, then move it back: M = T(cx, cy) · R(θ) · T(−cx, −cy). The "Shape centre" button above does exactly this.

01 What is it

Scaling changes the size of an object by multiplying its coordinates.

A scale factor larger than 1 enlarges, a factor between 0 and 1 shrinks, and a factor of exactly 1 leaves that direction untouched. Because the coordinates are multiplied, scaling about the origin also drags the object toward or away from the origin.

Deeper: a negative scale factor flips the object — Sx = −1 is exactly reflection about the y-axis. Reflection is a special case of scaling.

Uniform scaling

Sx = Sy — the shape grows or shrinks proportionally. Angles are preserved, so a square stays a square.

Non-uniform scaling

Sx ≠ Sy — the object stretches more in one direction. A circle becomes an ellipse and a square becomes a rectangle.

01 What is it

Reflection produces the mirror image of an object across a line or a point.

Hold a shape against a mirror: every point ends up on the opposite side, exactly the same distance away from the mirror line. In graphics the mirror is usually the x-axis, the y-axis, the origin or the line y = x.

Deeper: reflection reverses orientation. A triangle whose corners are labelled A→B→C counter-clockwise becomes clockwise after one reflection. Reflecting twice returns the original — the matrix is its own inverse.

01 What is it

Shearing slants an object by shifting one coordinate by an amount that depends on the other coordinate.

Push the top of a deck of cards sideways. The bottom card stays put, the top card moves the most, and the deck leans over. That is a shear: the higher a point sits, the further it slides. A rectangle becomes a parallelogram.

Deeper: shearing preserves area but not angles or lengths. Points already on the reference axis do not move at all.

01 The problem first

Translation cannot be written as a 2×2 matrix multiplication. Every other transformation can.

Rotation, scaling, reflection and shearing all multiply the coordinates. Translation adds to them:

x' = x + Tx     y' = y + Ty

No 2×2 matrix can produce a constant term, because every entry of the result is a multiple of x or y. So a pipeline that mixes moves with turns would need two different kinds of operation — multiply, then add, then multiply, then add. That is slow, error-prone, and impossible to collapse into a single matrix.

The fix: give every point a third coordinate that is always 1.
(x, y)→(x, y, 1)

This is called a homogeneous coordinate. The extra 1 gives the matrix a slot to inject a constant, which turns addition into multiplication. Now every transformation is a 3×3 matrix, and any sequence of them multiplies into one single matrix.

Deeper: in general a homogeneous point is (x·w, y·w, w) for any w ≠ 0, and you recover the Cartesian point by dividing by w. Using w = 1 is just the convenient normalized case. The full form is what makes perspective projection possible in 3D.

01 What is it

Several transformations can be multiplied together into one single matrix.

A game object might need to be resized, turned and then placed somewhere on screen. Instead of transforming every vertex three times, multiply the three matrices once and transform every vertex once. For a model with 50,000 vertices, that is 100,000 operations saved.

P' = T · R · S · P
Matrix multiplication is performed from right to left — the matrix closest to the point acts first.
S happens first  →  then R  →  then T
Deeper: this ordering comes from associativity: T(R(S·P)) = (T·R·S)·P. The product M = T·R·S is often called the composite, concatenated or model matrix.

Remember it this wayWearing a jacket and then a backpack is not the same as wearing the backpack and then the jacket. Same two actions, different order, very different result.
Teaching pointRotate-then-translate versus translate-then-rotate is the classic exam trap: T·R ≠ R·T. In the second case the object swings around the origin from its new position, tracing a wide arc. Demonstrate it live in the playground.

Why Why do we need matrices at all?

Without matrices

Every transformation needs its own set of equations and its own code path. Combining a move with a turn means chaining formulas by hand, and there is no single object you can store, invert or send to the GPU.

With matrices

One framework covers translation, rotation, scaling, reflection, shearing and any combination of them. Multiply once, apply to every vertex, invert to undo, and hand the result straight to the graphics pipeline.

Matrices give geometric transformations a common mathematical language.
